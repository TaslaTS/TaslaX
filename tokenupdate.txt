Old Apk bhi update kar dia gaya hai captcha wala apk jo users chahe iska istemal kar sakte hai isko download karne ke liye first QR ko scan kare aur install kare aur token fetch ke liye old button ka hi istemal kare.

Token APK ko update kar diya gaya hai. Kripya column number 3 se latest Token APK download kar lein aur “Fetch New Token” button ka use karke token generate karein.

**Kuch zaroori nirdesh:**

APK ko normal tareeke se open karein aur token generate karne ki process shuru karein. Payment page tak pahunchne ke dauran “availability” option par 4–5 baar click karte rahein.

Jab aap sahi tarah se payment section tak pahunch jaayein, tab apni User ID enter karke login karein. Login ke baad neeche “Send Token” ka option milega. Us par click karne par token bhej diya jayega, jise aap software me jaakar receive kar sakte hain.

Dhyaan rahe ki token send hone ke baad “About” section me jaayein aur neeche diye gaye “Clear App Data” button par click kar dein.

**Mahattvapurn soochna:**

Agar token generate karte waqt IP error ya kisi bhi tarah ka Akamai se related error aaye, to Spoof section me jaakar “Device Identifier” ke andar “Enable All Device Spoof” option ko ON kar dein. Iske baad APK ko restart karke dobara token generate karein.

Yeh option default me disabled hota hai. Zarurat padne par aap ise use kar sakte hain. Baaki jo bhi spoof options available hain, unka bhi istemal kar sakte hain. Lekin pehli baar token generate karte waqt bina kisi spoof ko enable kiye hi process try karein.
